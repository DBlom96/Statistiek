Suppose that $X$ is a continuous random variable with probability density function $f(x)$ and cumulative distribution function $F(x)$:

\begin{align*}
    f(x) &= \begin{cases} \frac{x^2}{9}, & \text{ for } 0 \leq x \leq 3 \\ 0, & \text{otherwise.} \end{cases} \\
    F(x) &= \begin{cases} \frac{x^3}{27}, & \text{ for } 0 \leq x \leq 3 \\ 0, & \text{otherwise.} \end{cases} \\
\end{align*}

What value does $P(X = 2)$ have?
